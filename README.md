# KIONI

**Meet Kioni**

![Kioni Banner](docs/banner.png)

## Features

- 🗣️ **Bilingual Chat** - Natural Swahili/English/Sheng code-switching
- 👁️ **Vision** - Camera integration for contextual awareness  
- 🎙️ **Voice** - Speech-to-text and text-to-speech in Swahili
- 🎨 **African Aesthetics** - Kitenge-inspired UI with animated character
- 🧠 **Cultural Intelligence** - Understands East African context, proverbs, and vibes
